# Guide de contribution

Les contributions peuvent améliorer les ingrédients, les repères de chauffe ou la documentation de service.

- Préserver une cuisson lente sur braises régulières.
- Distinguer les mesures précises des observations liées au foyer.
- Maintenir les consignes de ventilation et de sécurité.
- Garder un ton rigoureux, avec un humour gastronomique mesuré.

Toute proposition substantielle doit préciser les portions, les durées, le matériel et le résultat attendu.
